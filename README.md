# KARNATAKA-AI-TRIP-PLANNER
 *Karnataka AI Trip Planner at http://karnatakai-trip-planner.lovable.app is an AI app that creates personalized Karnataka trips in seconds. Enter destination, days, date &amp; budget to get a day-wise itinerary with attractions, food, stays &amp; transport for Mysore, Coorg, Hampi, Gokarna &amp; more.*
